ABOUT DRILLDECK

A focused practice space for Karnataka exam aspirants

DrillDeck is an independent online practice platform created by Bharat Poojari. It helps learners build configurable tests, practise available question-bank topics and review their progress without creating an account.

HOW IT WORKS

Quick and custom tests

Quick Test lets learners set a question count, difficulty and time for available subjects. Custom tests add control over papers, categories, datasets and topics.
